Syntax rules
  • First line *Name\ titles the diagram; last line *\ closes it.
  • Each line is *A, B\ comment. Elements in a line, and successive lines, are in series. The first element is the start.
  • branch: elements leave the path and end there (no return).
  • branch return / return^n: the branch rejoins the path n branch levels up (return = return^1).
  • branch wait: the branch stays open; the next line at the same indent continues it.
  • meet: a line where a returning branch rejoins (after its last element). Returns are matched to meets in the order their branches were opened.
  • end: marks the last element of the line as the end. Use A_1 for subscripts.
